# singen
Тестовое задание YADRO. Для команды разработки и моделирования алгоритмов связи для радиомодулей.

## Задание 4. Теоретичесик объяснить результаты измерений ошибки интерполяции и децимации
Чтобы увеличить sample rate сигнала, я сперва добавил промежуточные нули между отсчетами этого сигнала. Теперь в спектре этого сигнала появляются зеркальными компоненты на расстоянии +-F(частота сигнала) каждые n * FS(исходная частота дискретизации сигнала). Эти компоненты убираются фильтром низких частот, чтобы осталась только наша изначальная частота. В моем случае я также наложил на идельный прямоугольный фильтр нижних частот окно Хэмминга, чтобы `размазать` его и сделать конечным. После этого получаем тот же сигнал без паразитных частот. Далее децимация, я просто беру каждый n-ый отчет. В функции `check_error()` я сперва создаю `base_sin` на определенной частоте, интерполирую его, затем децимирую с тем же коэфициентом что и интерполировал. Затем считаю MAE(mean absolute error) временных отсчетов `base_sin` и `sin` который прошел этапы итерполяции, а затем децимации. Пример ошибки:
```bash
MAE после up и dec(sin40): 0.001400
MAE после up и dec(sin100): 0.001419
MAE после up и dec(sin300): 0.001419
```

## Запуск
Создать `venv`:
```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установить зависимости для python:
```bash
pip install -r requirements.txt
```

Запуск
```bash
python main.py
```
